# Public validation routes

These files are snapshots of OpenStreetMap geometries, used to exercise the engine with recognizable public places. Data is © OpenStreetMap contributors and available under the [Open Data Commons Open Database License](https://www.openstreetmap.org/copyright).

| File | Place | OSM source |
|---|---|---|
| `central-park.osm` | Central Park, New York | way 427818536 |
| `high-line.osm` | The High Line, New York | relation 7141751 |
| `brooklyn-bridge.osm` | Brooklyn Bridge, New York | way 375157262 |
| `golden-gate.osm` | Golden Gate Bridge, San Francisco | way 595194543 |

The snapshots are validation fixtures, not a promise of navigability. User-created work should come from the route they upload or authorize through a future activity integration.
